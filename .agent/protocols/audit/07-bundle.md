# audit / approve_judgment_axis

- PR merge unit is completion Bundle.
- checkpoint clear is not main merge approval.
- partial Bundle state is not mergeable while same-Bundle residue remains.
- State classification accuracy is necessary evidence, but it is not sufficient for main merge approval unless the PR has reached the completion Bundle boundary.
- Issue closed / aggregated / not_planned state is not implemented evidence.
- Remote CI / tests passing are evidence inputs, not semantic completion authority by themselves.
