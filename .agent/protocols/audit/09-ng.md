# audit / forbidden_shortcuts

- Summaryだけで判断しない
- PR metadata / mergeability だけで判断しない
- PR-side record を SSOT / code / test evidence の代替にしない
- `.agent/tools` output or `tool.log` を SSOT authority / proof completion / semantic audit judgment / implemented status evidence にしない
- ファイル存在だけで partial / implemented 判定しない
- completion_condition 未達のまま implemented 判定しない
- 実装を正本としてSSOTを後追いさせない
