# Checklist Templates and PR-specific Records

- `policy-judgment.md` and `boundary-identity.md` are blank templates.
- Do not keep PR- or issue-specific filled answers in template files under `.agent/checklists/`.
- Store filled checklists as temporary PR artifacts (for example under `.agent/tmp/` during work) and include only needed summary/judgment output in reports.
- Fixtures under `.agent/checklists/fixtures/` are self-test inputs and remain intentionally filled.
